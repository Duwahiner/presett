# Skill Registry

This registry tracks the skills available for the `presett` project SDD workflow.

## Active Skills
- `sdd-init`: Project initialization and context setup.
- `sdd-explore`: Exploration and requirements.
- `sdd-propose`: Change proposals.
- `sdd-spec`: Delta specs.
- `sdd-tasks`: Task planning.
- `sdd-apply`: Implementation.
- `sdd-verify`: Testing and verification.
- `sdd-archive`: Delta specs archiving.

## Testing Capabilities
- **Runner**: Vitest
- **Strict TDD**: Enabled
